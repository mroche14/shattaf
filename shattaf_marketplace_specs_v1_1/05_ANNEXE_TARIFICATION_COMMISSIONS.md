# 05 — Annexe : Tarification / commissions (plateforme)
**Date :** 24/01/2026

---

## 1. Principes
- Le Prestataire fixe librement son prix d’installation.
- La Plateforme facture des frais (commission) selon le modèle ci‑dessous, sans imposer de tarif.

## 2. Modèles possibles (choisir 1)
### Modèle A — Commission fixe (%)
- Commission : X % du montant installation HT/TT C (à préciser).
- Minimum : Y € / mission (option).

### Modèle B — Frais fixe
- Frais plateforme : X € / mission.

### Modèle C — Commission dynamique (incitation)
- Si prix installation <= T1 : commission C1%
- Si T1 < prix <= T2 : commission C2%
- Si prix > T2 : commission C3%

> Objectif : encourager une tarification “marché” sans imposer un prix.

## 3. Pénalités & frais (optionnels)
- No‑show Prestataire (après acceptation mission) : X €
- Annulation tardive client : Y € (si conditions CGV)
- Retard > Z minutes : impact statut partenaire (non financier).

## 4. Facturation B2B & e‑facturation
- Les frais plateforme peuvent être prélevés via PSP (application fee) et une facture B2B est émise.
- Anticiper l’e‑facturation B2B + e‑reporting (calendrier national, avec spécificités DOM). Voir `11_SOURCES.md`.
